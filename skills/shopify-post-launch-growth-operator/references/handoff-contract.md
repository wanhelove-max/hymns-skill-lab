# Growth Handoff Contract

The store-builder stage should create `content/growth-handoff.md` before this skill runs.

## Required Fields

- Store name:
- Store URL:
- Launch status:
- Brand positioning:
- Target customer:
- Primary categories:
- Priority products or collections:
- Ready landing routes:
- Product proof points:
- Material claims allowed:
- Claims banned or requiring proof:
- Installed app stack:
- Email/chat/review readiness:
- Shipping/returns promise:
- Open conversion risks:
- Open compliance risks:
- Next growth objective:

## If Missing

If the handoff file is missing, create a minimal version from `HANDOFF.md`, `PROGRESS.md`, `PLANS.md`, and current store docs. Mark assumptions clearly.

## Output Files

This growth skill may create:

- `content/growth-plan.md`
- `content/social-calendar.md`
- `content/creative-briefs/*.md`
- `content/ad-scripts/*.md`
- `content/email-campaigns/*.md`

It should not modify Shopify theme/app files directly.
