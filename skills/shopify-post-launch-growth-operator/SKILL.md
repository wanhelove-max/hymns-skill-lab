# Shopify Post-Launch Growth Operator

Use this skill after a Shopify store has reached launch readiness. It turns a finished store into a traffic and conversion system: social content, short videos, creator briefs, ad angles, landing-page routing, email/retention ideas, and analytics feedback loops.

## Required Input

Start from a handoff file when possible:

- `content/growth-handoff.md`
- `HANDOFF.md`
- `PROGRESS.md`
- `content/shopify-app-registry.md`

If `content/growth-handoff.md` is missing, ask the store-builder stage to create it or build a minimal one from current docs before planning campaigns.

## Boundary

This skill does not install or rebuild the store. It may recommend store changes, but implementation belongs to `shopify-independent-store-builder`, `store-fixer`, or a theme/development workflow.

Do not fabricate:

- reviews
- testimonials
- user-generated content
- before/after claims
- scarcity
- discounts
- charity/certification/history
- unsupported product claims

## Workflow

1. Read the growth handoff.
   - Brand promise, allowed claims, banned claims.
   - Target customer and product/category priorities.
   - Ready landing routes: homepage, collection, PDP, journal, material guide.
   - App stack and email/review/chat readiness.
   - Open risks.

2. Build the growth map.
   - Awareness: short videos, social posts, creator content, organic search snippets.
   - Consideration: product education, material explanations, styling content, comparison guides.
   - Conversion: PDP proof points, offer clarity, shipping/returns, cart reassurance.
   - Retention: care guide, review request, second-purchase ideas, winback.

3. Produce creative angles.
   - Pain/price angle: gold-look styling without solid-gold prices.
   - Material-truth angle: clearly labeled gold-tone/gold-plated jewelry.
   - Styling angle: one chain/ring/bracelet changes an outfit.
   - Gift angle: easy jewelry gifts without guessing fine-jewelry budgets.
   - Care angle: how to keep plated/gold-tone pieces looking better longer.
   - Mobile-shopping angle: clear size, material, returns, and support.

4. Create deliverables.
   - 15-30 short-video hooks.
   - 5-10 video scripts.
   - Creator brief.
   - Social caption bank.
   - Landing-page route map.
   - Email/SMS campaign ideas if opt-in systems are ready.
   - Testing plan: angle, audience, asset, landing route, metric.

5. Close the loop.
   - Define metrics: CTR, hold rate, add-to-cart, checkout started, conversion rate, CPA, ROAS, email signup rate.
   - Recommend next content batch from performance data.
   - Maintain `content/growth-plan.md`, `content/creative-briefs/`, and `content/social-calendar.md`.

6. Keep learning.
   - Use `references/learning-sources.md` to collect and classify social/platform/operator learnings.
   - Save learning notes under `content/growth-learning/`.
   - Treat unofficial advice as hypotheses until tested.
   - Let store analytics override generic playbooks after launch.

## Compliance For Jewelry

Allowed if true:

- gold-tone
- gold-look
- gold plated
- stainless steel
- PVD coating
- not solid gold
- everyday styling
- affordable gold look

Requires proof:

- waterproof
- tarnish-proof
- hypoallergenic
- nickel-free
- vermeil
- gold-filled
- solid gold
- handmade/artisan
- charity/donation
- certifications
