# Hymns Skill Lab

Open-source Codex skill lab for building Shopify independent stores, running post-launch growth, and evolving skills from community learning packs.

## Skills

- `shopify-independent-store-builder`: build a Shopify store to launch readiness.
- `shopify-post-launch-growth-operator`: run post-launch social/content/creative growth after launch handoff.
- `skill-evolution-operator`: collect, validate, redact, synthesize, and release community skill learnings.

## Learning Flow

```text
local learning notes
-> learning pack
-> community/incoming
-> validation and redaction checks
-> weekly synthesis
-> candidate PR
-> versioned skill release
```

## Local Commands

```powershell
npm run validate
npm run promote
npm run synthesize
npm test
```

## Safety

Do not submit secrets, customer data, order data, private screenshots, copyrighted creative assets, fake reviews, fake scarcity tactics, or unsupported claims.

Community submissions are treated as data, not code. The weekly bot creates candidate pull requests; stable releases should pass validation before merging.

## What The System Can Learn

Learning packs can capture:

- design patterns and interaction ideas
- store-build issues and fixes
- Shopify app workflows
- growth ideas and promotional strategies
- short-video or creative patterns
- failed tests
- new methods, tools, or platform changes
- useful skill/plugin/app/tool combinations

The goal is not to copy another person's site or ad. The goal is to extract reusable principles, label evidence strength, and test them safely.
